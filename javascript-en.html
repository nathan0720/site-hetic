Definition

JavaScript is a programming language. In the browser, it lets a page respond to user actions and change its content.

What is JavaScript used for?

It can open menus, check forms or change a theme. On our site, the theme button works through script.js.

How do you apply this JavaScript to an HTML page?

Write your instructions in script.js, then place this tag in the <head> of every page:

<script src="script.js" defer></script>

src gives the file path. With defer, HTML buttons and paragraphs exist before the script tries to find them. Write only JavaScript in the .js file; the <script> tags stay in the HTML file.

How does this page’s JavaScript work?

Every page loads script.js with defer. This file manages the theme, the demonstration and the active lesson highlight. The examples below come from our script. Code examples keep the French identifiers and text from the original site.

1. Find the button and apply a theme

We start by finding the theme button in the HTML. A function then groups the instructions needed to change its state.

const boutonTheme = document.querySelector('.bouton-theme');

function appliquerTheme(clair) {
    document.body.classList.toggle('theme-clair', clair);
    boutonTheme.textContent = clair ? textes.themeSombre : textes.themeClair;
    boutonTheme.setAttribute('aria-pressed', String(clair));
}

const declares a variable that we do not reassign. querySelector finds the button by its class. The clair parameter is either true or false. classList.toggle adds or removes theme-clair on the body, so CSS applies the right colours. clair ? ... : ... chooses the button’s label from textes, our language-specific labels. String(clair) converts the boolean into text for the accessibility attribute.

2. Restore the chosen theme

When the page loads, we try to read the theme stored in the browser.

try {
    appliquerTheme(localStorage.getItem('nathan-simon-theme') === 'clair');
} catch {
    appliquerTheme(false);
}
boutonTheme.hidden = false;

localStorage stores a value in the browser. getItem reads it, and === checks whether it equals clair. If storage access fails, catch activates the dark theme. Finally, hidden = false shows the button.

3. Respond to a click on the theme button

An event listener waits for the user to click the button.

boutonTheme.addEventListener('click', function () {
    const clair = !document.body.classList.contains('theme-clair');
    appliquerTheme(clair);
    try {
        localStorage.setItem('nathan-simon-theme', clair ? 'clair' : 'sombre');
    } catch {
        // Le bouton reste utilisable si le stockage est désactivé.
    }
});

contains checks whether the class is present. The ! symbol reverses the answer: if the light theme is active, we switch to dark, and vice versa. We apply the new theme, then setItem saves the choice for other pages and future visits when the browser allows it.

4. Make the demonstration button work

Further down this page, the “Click here” button changes the paragraph immediately below it.

const boutonDemo = document.querySelector('#bouton-demo');
const messageDemo = document.querySelector('#message-demo');
if (boutonDemo && messageDemo) {
    boutonDemo.addEventListener('click', function () {
        messageDemo.textContent = textes.demo;
    });
}

The # symbol targets an HTML identifier. if (boutonDemo && messageDemo) checks that both elements exist. This avoids errors on other pages, which load the same script without the demonstration. On a click, textContent replaces the paragraph text with the message from textes.demo. The HTML aria-live="polite" attribute allows screen readers to announce the update.

5. Highlight the current lesson

The script compares the open filename with the destination of each lesson link.

const pageActuelle = window.location.pathname.split('/').pop();
document.querySelectorAll('.langages a').forEach(function (lien) {
    if (lien.getAttribute('href') === pageActuelle) {
        lien.setAttribute('aria-current', 'page');
    }
});

window.location.pathname gives the page path. split separates it at each slash, and pop retrieves the last part, such as javascript-en.html. querySelectorAll finds all lesson links, and forEach goes through them. When a link matches the open page, we add aria-current="page". CSS uses that attribute to highlight it. HTML links handle the navigation itself.

6. Show the site in French or English

The FR and EN buttons open two versions of the same page. For example, html.html is French and html-en.html is English. Lesson links then stay in the chosen language.

const anglais = document.documentElement.lang === 'en';

In each HTML file, the lang attribute is either fr or en. Our textes object chooses labels for the theme, copy button and demonstration. This makes textes.demo and textes.themeClair follow the page language.

7. Copy an example to the clipboard

The script adds a “Copy code” button before each example. It reads only the content of <code>, copying plain text without the presentation markup. Here is the simplified idea:

const code = document.querySelector("pre > code");
await navigator.clipboard.writeText(code.textContent);

In our actual script, this instruction runs inside an async function called on a click. await waits for copying to finish before displaying “Copied!”. On GitHub Pages, HTTPS allows this API to be used. If it fails, we try a temporary text field as a fallback. If copying still fails, a message suggests copying manually.
