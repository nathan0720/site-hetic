Définition

HTML signifie HyperText Markup Language. C’est un langage de balisage : il décrit le contenu et la structure d’une page web.

À quoi sert HTML ?

Il sert à créer des titres, des paragraphes, des liens, des images ou des formulaires. Les balises indiquent au navigateur le rôle de chaque élément.

Comment a-t-on construit cette page ?

Cette page est le fichier html.html. Les pages css.html et javascript.html reprennent la même structure. Voici les morceaux de code réellement utilisés et leur rôle.

1. Préparer la page et charger les fichiers

Au début du fichier, on indique que le document est en HTML et que le texte est en français. Dans <head>, on prépare les informations de la page.

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Comprendre HTML — Nathan &amp; Simon</title>
    <link rel="stylesheet" href="style.css">
    <script src="script.js" defer></script>
</head>

charset="UTF-8" permet d’afficher les accents. La ligne viewport permet d’adapter l’affichage à la largeur du téléphone. <title> donne le nom de l’onglet. <link> charge notre CSS et <script> charge notre JavaScript. Avec defer, le script attend que le HTML soit analysé avant de s’exécuter.

2. Afficher le logo et le bouton de thème

L’en-tête se trouve dans <header>. Le logo est une image placée à l’intérieur d’un lien vers l’accueil.

<header class="entete">
    <a class="signature" href="index.html" aria-label="Accueil">
        <img class="logo-hetic" src="hetic-logo.svg" alt="HETIC" width="52" height="70">
    </a>
    <button class="bouton-theme" type="button" aria-pressed="false" hidden>☀ Thème clair</button>
</header>

src indique le fichier du logo et alt donne un texte de remplacement. Les attributs class permettent au CSS de cibler ces éléments. Le bouton est caché avec hidden au départ : notre JavaScript le rend visible lorsqu’il est prêt. aria-pressed indique aux outils d’accessibilité si le thème clair est activé.

3. Passer d’une page à l’autre

Les liens HTML assurent la navigation. Quand on clique sur CSS, le navigateur ouvre le fichier css.html.

<nav class="langages" aria-label="Les cours">
    <a href="html.html">HTML</a>
    <a href="css.html">CSS</a>
    <a href="javascript.html">JavaScript</a>
</nav>

<nav> regroupe les liens de navigation. Chaque attribut href donne le nom du fichier à ouvrir, situé dans le même dossier. Ces liens fonctionnent même sans JavaScript.

4. Organiser les explications

Le contenu principal est placé dans <main class="cours">. Le titre principal utilise <h1>, puis chaque bloc d’explication possède un titre <h2>.

<section class="bloc-cours">
    <h2>Définition</h2>
    <p>HTML signifie HyperText Markup Language. C’est un langage de balisage : il décrit le contenu et la structure d’une page web.</p>
</section>

La classe bloc-cours donne à chaque section son cadre et ses espacements grâce au CSS. Les extraits de code sont affichés dans <pre><code> pour conserver les retours à la ligne. Pour montrer une balise sans que le navigateur l’interprète, on écrit par exemple &lt;h1&gt; dans le fichier HTML. Enfin, <footer> contient la signature en bas de la page.

Relier HTML, CSS et JavaScript : les trois fichiers

Dans notre dossier, on place index.html, style.css et script.js côte à côte. Chaque page HTML charge les deux autres fichiers dans son <head>.

<link rel="stylesheet" href="style.css">
<script src="script.js" defer></script>

rel="stylesheet" indique au navigateur qu’il s’agit d’une feuille de style. href pointe vers le CSS et src vers le JavaScript. defer permet de télécharger le script pendant la lecture du HTML, puis de l’exécuter quand les éléments de la page sont disponibles. La partie ?v=local-ia-1 ajoutée dans nos vraies pages sert à demander la nouvelle version de ces fichiers au navigateur.

Comment le CSS reconnaît-il les éléments HTML ?

Dans le HTML, on donne une classe à un élément. Dans le CSS, on cible cette classe avec un point devant son nom. Ici, c’est le même principe que pour nos blocs de cours.

<section class="bloc-cours">
    <h2>Notre premier cours</h2>
</section>

Dans style.css :

.bloc-cours {
    padding: 24px;
    border: 1px solid var(--bordure);
}

Ces deux morceaux se placent dans des fichiers séparés : le HTML dans la page .html, et la règle .bloc-cours dans style.css. Les variables comme --bordure sont définies dans :root.

Comment JavaScript retrouve-t-il un élément HTML ?

On peut donner un identifiant avec id, puis le retrouver avec document.querySelector et un #. Notre démonstration utilise ces éléments HTML :

<button id="bouton-demo" type="button">Clique ici</button>
<p id="message-demo" aria-live="polite">Ce texte va changer quand tu cliqueras.</p>

Dans script.js, document.querySelector("#bouton-demo") retrouve ce bouton. On écoute ensuite son événement click pour modifier le paragraphe #message-demo. Tu peux tester cet exemple sur la page JavaScript.

Les trois travaillent ensemble

HTML définit le contenu, CSS s’occupe de son apparence et JavaScript ajoute des interactions.
