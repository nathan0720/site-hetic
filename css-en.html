What is CSS?

Definition

CSS stands for Cascading Style Sheets. This language defines how HTML elements are presented.

What is CSS used for?

CSS lets us choose colours, fonts, spacing and the arrangement of elements. It also adapts the layout for phones and computers.

How do you apply this CSS to an HTML page?

Write your rules in style.css, then add this line inside the <head> of every HTML page:

<link rel="stylesheet" href="style.css">

The path is relative to the HTML file. Since our files share a folder, the filename is enough. An HTML class such as class="bloc-cours" is targeted by .bloc-cours in CSS. Updating the shared file changes the appearance of every page that loads it.

How did we style this page?

All our pages load the same style.css file, keeping the same colours, logo and lesson blocks throughout the site. These examples come from that file.

1. Choose the colours

We use the mint green, deep green and white from HETIC’s website. In :root, we define reusable colour variables. For example, --texte is the main text colour.

:root {
    color-scheme: dark;
    --fond: #001810;
    --fond-secondaire: #00634B;
    --texte: #ffffff;
    --texte-discret: #c4ddd5;
    --accent: #2EE7C4;
    --bordure: #2ee7c433;
    --surface: #ffffff08;
}

We then use var(--texte) or var(--accent) in CSS rules. The body background blends --fond and --fond-secondaire. The body.theme-clair rule replaces these variables when JavaScript activates the light theme.

2. Centre the content and limit its width

These rules leave space at the sides and prevent explanations from stretching across the entire screen.

.entete, main, footer {
    width: min(1080px, calc(100% - 48px));
    margin-inline: auto;
}

.cours {
    max-width: 760px;
    padding-block: 28px 60px;
}

min() picks the smaller of two widths. calc(100% - 48px) reserves 24 pixels on each side. margin-inline: auto centres the content. On lesson pages, max-width limits it to 760 pixels, and padding-block adds space above and below.

3. Create the explanation blocks

Each section on this page has the bloc-cours class. The dot in .bloc-cours means the selector targets a class.

.bloc-cours {
    padding: 24px;
    margin-bottom: 20px;
    border: 1px solid var(--bordure);
    border-radius: 18px;
    background: var(--surface);
}

padding adds space inside a block. margin-bottom separates it from the next block. border draws the outline, border-radius rounds the corners, and background adds a slightly transparent fill. Later glass-effect rules add the final blur and reflections.

4. Align the links and highlight the current page

We use Flexbox to place the HTML, CSS and JavaScript links next to each other.

.langages {
    display: flex;
    justify-content: center;
    flex-wrap: wrap;
    gap: 12px;
    margin-top: 20px;
}

.langages a {
    display: flex;
    flex-direction: column;
    align-items: flex-start;
    gap: 4px;
    min-width: 150px;
    min-height: 80px;
    padding: 14px 20px;
    border-radius: 16px;
    text-align: left;
    transition: transform 0.2s, border-color 0.2s;
}

justify-content: center centres the links. gap spaces them apart, and flex-wrap: wrap lets them move to another line. min-height: 80px and padding enlarge the clickable area. flex-direction: column stacks the language name and description. :hover changes their appearance when the pointer is over them. The [aria-current="page"] selector highlights the open lesson; JavaScript adds this attribute.

5. Display code and adapt to screen sizes

Code examples preserve line breaks through the HTML <pre> tag. CSS adds a border and enables horizontal scrolling when a line is too long.

pre {
    overflow-x: auto;
    padding: 18px;
    border-radius: 10px;
    background: var(--fond);
    border: 1px solid var(--bordure);
}

.cours h1 {
    font-size: clamp(38px, 7vw, 64px);
}

clamp() adapts the heading to the screen width while keeping its size between 38 and 64 pixels. Our @media rules also reduce some spacing on small screens. The logo uses object-fit: contain to preserve its proportions. In dark mode, filter: invert(1) turns the black logo white.

6. Create the translucent glass effect

Cards, lesson blocks and buttons use a transparent fill with a subtle white gradient. Green shapes in the background remain visible through them, creating a glass effect inspired by Liquid Glass.

-webkit-backdrop-filter: blur(20px) saturate(150%);
backdrop-filter: blur(20px) saturate(150%);

backdrop-filter blurs what is behind the block. blur(20px) sets the blur, and saturate(150%) boosts the colours behind the glass. The -webkit- version supports some Safari versions. We use @supports to keep a more opaque background when the effect is unavailable.

A fine border and a light inset shadow create a reflection along the glass edge. Colours are grouped in --verre, --reflet and --ombre-verre; they also change with the light theme.

All three work together

HTML defines the content, CSS handles its appearance, and JavaScript adds interactions.
