View the files on GitHub ↗

1. Create the repository

In Safari, we signed in to GitHub and opened New repository. We named it site-hetic, chose Public and clicked Create repository.

2. Upload the files to the root

In the new repository, we clicked uploading an existing file, then Choose your files. We selected the pages, CSS, JavaScript and logos. index.html must be directly in the repository root, not inside another folder.

3. Save with a commit

We entered a summary and clicked Commit changes. The files were saved in the history of the main branch. A commit is a version of the project that GitHub keeps.

4. Enable GitHub Pages

In the repository, we opened Settings → Pages. Under Build and deployment, we chose Deploy from a branch, the main branch and the / (root) folder, then clicked Save.

5. Wait for deployment

The Actions tab shows the pages build and deployment workflow. We waited for its green Success status and opened the site link. The first deployment can take a few minutes.

6. Update the site

For later improvements, we used Add file → Upload files, replaced the changed files and saved another commit on main. GitHub Pages republishes the site automatically. We then checked the result in Safari.

Links use relative paths such as style.css and html.html. They work both in the local folder and under /site-hetic/.

Publish what you built in the lab

Click “My project as a ZIP” in the practice lab, unzip it and upload the files to your own repository. It contains an index.html linked to style.css and script.js. Then follow the Pages steps above.

If the site does not appear

  • Check that the file is named index.html, all lowercase.
  • Check main and / (root) in Settings → Pages.
  • Read the result of the latest deployment in Actions.
  • In Safari, use ⌘⌥R to reload from the origin if an old version is still displayed.
