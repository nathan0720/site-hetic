Définition

CSS signifie Cascading Style Sheets, ou feuilles de style en cascade. Ce langage définit la présentation des éléments HTML.

À quoi sert CSS ?

Il permet de choisir les couleurs, les polices, les espacements et la disposition des éléments. Il permet aussi d’adapter la mise en page aux téléphones et aux ordinateurs.

Comment appliquer ce CSS à une page HTML ?

On écrit les règles dans style.css, puis on ajoute cette ligne dans le <head> de chaque page HTML :

<link rel="stylesheet" href="style.css">

Le chemin est relatif au fichier HTML : comme nos fichiers sont dans le même dossier, le nom suffit. Une classe comme class="bloc-cours" dans le HTML est ciblée par .bloc-cours dans le CSS. Une modification du fichier partagé met à jour l’apparence de toutes les pages qui le chargent.

Comment a-t-on mis cette page en forme ?

Toutes nos pages chargent le même fichier style.css. On garde ainsi les mêmes couleurs, le même logo et les mêmes blocs sur tout le site. Voici des extraits réellement utilisés.

1. Choisir les couleurs

On reprend le vert menthe, le vert profond et le blanc du site HETIC. Dans :root, on définit des variables de couleur réutilisables. Par exemple, --texte est la couleur principale du texte.

:root {
    color-scheme: dark;
    --fond: #001810;
    --fond-secondaire: #00634B;
    --texte: #ffffff;
    --texte-discret: #c4ddd5;
    --accent: #2EE7C4;
    --bordure: #2ee7c433;
    --surface: #ffffff08;
}

On utilise ensuite var(--texte) ou var(--accent) dans les règles CSS. Le fond du body est un dégradé entre --fond et --fond-secondaire. La règle body.theme-clair remplace ces variables quand JavaScript active le thème clair.

2. Centrer le contenu et limiter sa largeur

Ces règles laissent de l’espace sur les côtés et évitent que les explications prennent toute la largeur de l’écran.

.entete, main, footer {
    width: min(1080px, calc(100% - 48px));
    margin-inline: auto;
}

.cours {
    max-width: 760px;
    padding-block: 28px 60px;
}

min() choisit la plus petite des deux largeurs. calc(100% - 48px) réserve 24 pixels de chaque côté. margin-inline: auto centre le contenu. Sur les pages de cours, max-width limite la largeur à 760 pixels et padding-block ajoute de l’espace en haut et en bas.

3. Créer les blocs d’explication

Chaque section de cette page porte la classe bloc-cours. Le point devant .bloc-cours indique que le sélecteur cible une classe.

.bloc-cours {
    padding: 24px;
    margin-bottom: 20px;
    border: 1px solid var(--bordure);
    border-radius: 18px;
    background: var(--surface);
}

padding crée de l’espace à l’intérieur du bloc. margin-bottom sépare les blocs entre eux. border dessine le contour, border-radius arrondit les coins et background ajoute un fond légèrement transparent.

4. Aligner les liens et montrer la page ouverte

On utilise Flexbox pour placer les liens HTML, CSS et JavaScript côte à côte.

.langages {
    display: flex;
    justify-content: center;
    flex-wrap: wrap;
    gap: 12px;
    margin-top: 20px;
}

.langages a {
    display: flex;
    flex-direction: column;
    align-items: flex-start;
    gap: 4px;
    min-width: 150px;
    min-height: 80px;
    padding: 14px 20px;
    border-radius: 16px;
    text-align: left;
    transition: transform 0.2s, border-color 0.2s;
}

justify-content: center centre les liens. gap les espace et flex-wrap: wrap les autorise à passer à la ligne. min-height: 80px et les espacements agrandissent la zone cliquable. Le nom du langage et sa description sont empilés avec flex-direction: column. :hover change leur apparence au survol. Le sélecteur [aria-current="page"] met en évidence le cours ouvert ; cet attribut est ajouté par notre JavaScript.

5. Afficher le code et adapter la page aux écrans

Les exemples de code gardent leurs retours à la ligne grâce à la balise HTML <pre>. Le CSS leur ajoute un cadre et permet de défiler horizontalement si une ligne est trop longue.

pre {
    overflow-x: auto;
    padding: 18px;
    border-radius: 10px;
    background: var(--fond);
    border: 1px solid var(--bordure);
}

.cours h1 {
    font-size: clamp(38px, 7vw, 64px);
}

clamp() adapte le titre à la largeur de l’écran tout en gardant une taille entre 38 et 64 pixels. Nos règles @media réduisent aussi certains espacements sur les petits écrans. Le logo utilise object-fit: contain pour garder ses proportions ; en thème sombre, filter: invert(1) rend le logo noir visible en blanc.

6. Créer l’effet de verre translucide

Les cartes, les blocs de cours et les boutons utilisent un fond transparent avec un léger dégradé blanc. Les formes vertes du fond restent visibles à travers : cela donne un effet de verre, inspiré du Liquid Glass.

-webkit-backdrop-filter: blur(20px) saturate(150%);
backdrop-filter: blur(20px) saturate(150%);

backdrop-filter floute ce qui se trouve derrière le bloc. blur(20px) règle le flou et saturate(150%) renforce les couleurs derrière le verre. La version -webkit- assure la compatibilité avec certaines versions de Safari. On utilise @supports pour garder un fond plus opaque si cet effet n’est pas disponible.

Une bordure fine et une ombre intérieure claire créent un reflet sur le bord du verre. Les couleurs sont regroupées dans --verre, --reflet et --ombre-verre ; elles changent aussi avec le thème clair.

Les trois travaillent ensemble

HTML définit le contenu, CSS s’occupe de son apparence et JavaScript ajoute des interactions.
