Voir les fichiers sur GitHub ↗

1. Créer le dépôt

Dans Safari, nous nous sommes connectés à GitHub, puis avons ouvert New repository. Nous avons nommé le dépôt site-hetic, choisi Public, puis cliqué sur Create repository.

2. Envoyer les fichiers à la racine

Dans le nouveau dépôt : uploading an existing file, puis Choose your files. Nous avons sélectionné les pages, le CSS, le JavaScript et les logos. index.html doit être directement à la racine du dépôt, pas caché dans un sous-dossier.

3. Enregistrer avec un commit

Nous avons écrit un résumé, puis cliqué sur Commit changes. Les fichiers sont alors enregistrés dans l’historique de la branche main. Un commit est une version du projet que GitHub conserve.

4. Activer GitHub Pages

Dans le dépôt : Settings → Pages. Dans Build and deployment, nous avons choisi Deploy from a branch, la branche main, puis le dossier / (root). Enfin, nous avons cliqué sur Save.

5. Attendre le déploiement

L’onglet Actions affiche le workflow pages build and deployment. Nous avons attendu son statut vert Success, puis ouvert le lien du site. Le premier déploiement peut prendre quelques minutes.

6. Mettre le site à jour

Pour les améliorations suivantes, nous avons utilisé Add file → Upload files, remplacé les fichiers modifiés et enregistré un nouveau commit sur main. GitHub Pages republie automatiquement le site. Nous avons ensuite vérifié le résultat dans Safari.

Les fichiers doivent rester ensemble

site-hetic/
├── index.html
├── style.css
├── script.js
├── html.html
├── css.html
├── javascript.html
├── entrainement.html
├── entrainement.js
└── … logos et versions anglaises / logos and English versions

Les liens utilisent des chemins relatifs comme style.css et html.html. Ils fonctionnent dans le dossier local comme sous /site-hetic/.

Publier ce que tu as codé dans le labo

Clique sur « Mon projet en ZIP » dans l’entraînement, décompresse le ZIP et envoie ses fichiers dans ton propre dépôt. Le ZIP contient un index.html relié à style.css et script.js. Reprends ensuite les étapes Pages ci-dessus.

Si le site ne s’affiche pas

  • Vérifie que le fichier s’appelle bien index.html, tout en minuscules.
  • Vérifie main et / (root) dans Settings → Pages.
  • Lis le résultat du dernier déploiement dans Actions.
  • Dans Safari, utilise ⌘⌥R pour recharger depuis l’origine si une ancienne version reste affichée.
