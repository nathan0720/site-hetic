Définition

JavaScript est un langage de programmation. Dans le navigateur, il permet de faire réagir une page aux actions des utilisateurs et de modifier son contenu.

À quoi sert JavaScript ?

Il permet par exemple d’ouvrir un menu, de vérifier un formulaire ou de changer un thème. Sur notre site, le bouton de thème fonctionne grâce au fichier script.js.

Comment appliquer ce JavaScript à une page HTML ?

On écrit les instructions dans script.js, puis on place cette balise dans le <head> de chaque page :

<script src="script.js" defer></script>

src donne le chemin du fichier. Grâce à defer, les boutons et paragraphes HTML existent avant que le script essaie de les retrouver. On écrit uniquement du JavaScript dans le fichier .js ; les balises <script> restent dans le fichier HTML.

Comment fonctionne le JavaScript de cette page ?

Toutes les pages chargent script.js avec defer. Ce fichier gère le thème, la petite démonstration et la mise en évidence du cours ouvert. Les extraits ci-dessous viennent de notre script.

1. Récupérer le bouton et appliquer un thème

On commence par récupérer le bouton de thème dans le HTML. Une fonction regroupe ensuite les instructions à exécuter pour changer son état.

const boutonTheme = document.querySelector('.bouton-theme');

function appliquerTheme(clair) {
    document.body.classList.toggle('theme-clair', clair);
    boutonTheme.textContent = clair ? textes.themeSombre : textes.themeClair;
    boutonTheme.setAttribute('aria-pressed', String(clair));
}

const déclare une variable qu’on ne réaffecte pas. querySelector trouve le bouton grâce à sa classe. Le paramètre clair vaut true ou false. classList.toggle ajoute ou retire theme-clair sur le body : le CSS applique alors les bonnes couleurs. L’expression clair ? ... : ... choisit le texte du bouton. String(clair) transforme le booléen en texte pour l’attribut d’accessibilité.

2. Retrouver le thème choisi

Au chargement de la page, on essaie de lire le thème enregistré dans le navigateur.

try {
    appliquerTheme(localStorage.getItem('nathan-simon-theme') === 'clair');
} catch {
    appliquerTheme(false);
}
boutonTheme.hidden = false;

localStorage mémorise une valeur dans le navigateur. getItem relit cette valeur et === vérifie si elle vaut clair. Si l’accès au stockage échoue, catch active le thème sombre. Enfin, hidden = false affiche le bouton.

3. Réagir au clic sur le thème

Un écouteur d’événement attend que l’utilisateur clique sur le bouton.

boutonTheme.addEventListener('click', function () {
    const clair = !document.body.classList.contains('theme-clair');
    appliquerTheme(clair);
    try {
        localStorage.setItem('nathan-simon-theme', clair ? 'clair' : 'sombre');
    } catch {
        // Le bouton reste utilisable si le stockage est désactivé.
    }
});

contains vérifie si la classe est présente. Le signe ! inverse la réponse : si le thème clair est actif, on passe au sombre, et inversement. On applique ce nouveau thème puis setItem enregistre le choix pour les prochaines pages ou visites, si le navigateur l’autorise.

4. Faire fonctionner le bouton de démonstration

Plus bas dans cette page, le bouton « Clique ici » modifie le texte du paragraphe qui le suit.

const boutonDemo = document.querySelector('#bouton-demo');
const messageDemo = document.querySelector('#message-demo');
if (boutonDemo && messageDemo) {
    boutonDemo.addEventListener('click', function () {
        messageDemo.textContent = textes.demo;
    });
}

Le symbole # cible un identifiant HTML. La condition if (boutonDemo && messageDemo) vérifie que les deux éléments existent. Cela évite une erreur sur les autres pages, qui chargent le même script sans avoir cette démonstration. Au clic, textContent remplace le texte du paragraphe. Son attribut HTML aria-live="polite" permet aux lecteurs d’écran d’annoncer la modification.

5. Mettre en évidence le cours ouvert

Le script compare le nom du fichier ouvert avec la destination de chaque lien de cours.

const pageActuelle = window.location.pathname.split('/').pop();
document.querySelectorAll('.langages a').forEach(function (lien) {
    if (lien.getAttribute('href') === pageActuelle) {
        lien.setAttribute('aria-current', 'page');
    }
});

window.location.pathname donne le chemin de la page. split le découpe aux barres obliques et pop récupère le dernier morceau, par exemple javascript.html. querySelectorAll récupère tous les liens de cours et forEach les parcourt. Si un lien correspond à la page ouverte, on lui ajoute aria-current="page". Le CSS utilise cet attribut pour le colorer. Le changement de page lui-même est assuré par les liens HTML.

6. Afficher le site en français ou en anglais

Les boutons FR et EN ouvrent deux versions de la même page. Par exemple, html.html est en français et html-en.html en anglais. Les liens de cours restent ensuite dans la langue choisie.

const anglais = document.documentElement.lang === 'en';

Dans chaque fichier HTML, l’attribut lang indique fr ou en. Notre objet textes choisit alors les libellés du thème, du bouton de copie et de la démonstration. Ainsi, textes.demo et textes.themeClair suivent la langue de la page.

7. Copier un exemple dans le presse-papiers

Le script ajoute un bouton « Copier le code » devant chaque extrait. Il lit uniquement le contenu du <code>, pour copier du texte sans les balises de présentation. Voici le principe simplifié :

const code = document.querySelector("pre > code");
await navigator.clipboard.writeText(code.textContent);

Dans notre vrai script, cette instruction se trouve dans la fonction async appelée lors du clic. await attend la fin de la copie avant d’afficher « Copié ! ». Sur GitHub Pages, la connexion HTTPS permet d’utiliser cette API. Si elle échoue, on essaie une méthode de repli avec un champ de texte temporaire ; si aucune copie n’est possible, un message propose de copier manuellement.
