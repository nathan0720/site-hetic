Definition

HTML stands for HyperText Markup Language. It is a markup language that describes the content and structure of a web page.

What is HTML used for?

It creates headings, paragraphs, links, images and forms. Tags tell the browser what each element is for.

How did we build this page?

This is html-en.html, the English version of html.html. The CSS and JavaScript pages use the same structure. Below are the actual building blocks and what they do. Code examples keep the French names and text from the original site.

1. Set up the page and load its files

The beginning of the file declares an HTML document and its language. The <head> contains information about the page. The original French page uses lang="fr"; this English version uses lang="en".

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Comprendre HTML — Nathan &amp; Simon</title>
    <link rel="stylesheet" href="style.css">
    <script src="script.js" defer></script>
</head>

charset="UTF-8" allows accented characters to display correctly. The viewport line adapts the layout to a phone’s width. <title> names the browser tab. <link> loads our CSS and <script> loads our JavaScript. With defer, the script waits until the HTML has been parsed before it runs.

2. Display the logo and theme button

The header lives inside <header>. The logo is an image inside a link back to the home page.

<header class="entete">
    <a class="signature" href="index.html" aria-label="Accueil">
        <img class="logo-hetic" src="hetic-logo.svg" alt="HETIC" width="52" height="70">
    </a>
    <button class="bouton-theme" type="button" aria-pressed="false" hidden>☀ Thème clair</button>
</header>

src points to the logo file and alt provides replacement text. The class attributes let CSS target these elements. The button starts out hidden with hidden; JavaScript shows it when it is ready. aria-pressed tells assistive technology whether the light theme is active.

3. Navigate between pages

HTML links provide navigation. Clicking CSS opens css.html in French, or css-en.html in English.

<nav class="langages" aria-label="Les cours">
    <a href="html.html">HTML</a>
    <a href="css.html">CSS</a>
    <a href="javascript.html">JavaScript</a>
</nav>

<nav> groups the navigation links. Each href gives the name of the file to open in the same folder. These links work even without JavaScript.

4. Organise the explanations

The main content goes inside <main class="cours">. The main heading uses <h1>, and each explanation has an <h2> heading.

<section class="bloc-cours">
    <h2>Définition</h2>
    <p>HTML signifie HyperText Markup Language. C’est un langage de balisage : il décrit le contenu et la structure d’une page web.</p>
</section>

The bloc-cours class gives each section its border and spacing through CSS. Examples use <pre><code> to preserve line breaks. To display a tag without the browser interpreting it, we write something like &lt;h1&gt; in the HTML file. Finally, <footer> contains the signature at the bottom.

Connect HTML, CSS and JavaScript: three files

We place index.html, style.css and script.js next to each other in the same folder. Every HTML page loads the other two files in its <head>.

<link rel="stylesheet" href="style.css">
<script src="script.js" defer></script>

rel="stylesheet" tells the browser that the file is a stylesheet. href points to the CSS and src to the JavaScript. defer lets the script download while the HTML is being parsed, then run once the page elements are available. The ?v=local-ia-1 suffix in our actual pages asks the browser to load the new version of these files.

How does CSS recognise HTML elements?

In HTML, we give an element a class. In CSS, we target that class with a dot before its name. Our lesson blocks use this same approach.

<section class="bloc-cours">
    <h2>Notre premier cours</h2>
</section>

In style.css:

.bloc-cours {
    padding: 24px;
    border: 1px solid var(--bordure);
}

Put these two parts in separate files: the HTML in your .html page, and the .bloc-cours rule in style.css. Variables such as --bordure are defined in :root.

How does JavaScript find an HTML element?

Give an element an id, then find it with document.querySelector and a #. Our demonstration uses these HTML elements:

<button id="bouton-demo" type="button">Clique ici</button>
<p id="message-demo" aria-live="polite">Ce texte va changer quand tu cliqueras.</p>

In script.js, document.querySelector("#bouton-demo") finds this button. We then listen for its click event to update the #message-demo paragraph. You can try the example on the JavaScript page.

All three work together

HTML defines the content, CSS handles its appearance, and JavaScript adds interactions.
